## 📖 About the Project

**Hearth & Haven** is an indie mobile game designed to deliver a relaxing, cozy experience right in your pocket. Developed by an AI enthusiast alongside family playtesting, this project serves as both a warm casual game and a hands-on exploration of end-to-end mobile development using modern AI tools for design, logic, and asset pipelines.

### Core Highlights
* **Cozy Gameplay:** Low-stress, rewarding game loops crafted for casual daily play.
* **AI-Assisted Workflow:** Concept art, sound design, and prototyping accelerated using AI generation tools.
* **Ad-Supported & Accessible:** Free-to-play with non-intrusive, player-friendly rewarded and casual ad placements.
